# Breadcrumb Trail：Mac 离线赛道地图

基于 pauljohnston2025/breadcrumb-garmin 的非商业 Fork，保留上游署名和
CC BY-NC-SA 4.0 许可。Mac 端与 `watch-offline/` 是新增的 USB 离线版本；
上游原有的手机配套功能保留在 `source/`。

## 日常使用

1. 打开 `build/Breadcrumb Trail.app`。
2. 拖入比赛 GPX，选择“路线周边”的额外范围（默认 300 米）与细节。
3. 点击 **下载并预览地图**。地图可拖动、缩放，蓝线为完整 GPX，绿色为起点。
4. 确认预览，点击 **生成手表地图**。连接 255，检测型号后点击 **安装到 255**。
5. 等待“文件已写入并校验”，再拔线。打开要使用地图的运动，例如徒步或越野跑，
   长按左侧中键 UP → **徒步设置**（或 **越野跑设置**）→ 数据页面 → 新增或编辑一个页面。
6. 先将这个页面的 **布局设为 1 个字段（全屏）**，再将唯一的数据字段设为
   Connect IQ → **Breadcrumb Trail**。不要在三格页面里重复添加地图。

每种运动的数据页面分别保存。只在跑步中添加过地图，并不会自动添加到徒步或越野跑；
在需要使用地图的每种运动里各设置一次即可，无需重新下载、安装同一张地图。

安装过程会重新核对型号、程序校验值和可用空间。地图保存在应用资源中，拔线后
无需手机或网络。地图朝北，红点为 GPS 当前位置，短线为行进方向。
未开始运动时，没有定位或人在外地会自动显示全程预览；进入地图范围后自动跟随。
正式记录运动时超出地图范围，会保留真实位置并提示“当前位置超出地图”，不会跳回起点。
请使用单字段全屏页面；小页面会提示“请设为单字段全屏”（英文为 `Use 1-field page`）。
这个提示代表程序已启动，但布局空间不足；请修改页面的“布局”，而非只更换某一格的内容。
如果全屏后显示 IQ 错误图标或白屏，才需要进一步读取程序错误日志。

每次安装替换本工具的当前赛事，Mac 保留之前保存的 GPX、地图缓存和安装备份。
上游商店版使用不同应用 ID，不会被这个离线版本替换。文件名为
`GARMIN/APPS/BCTRAIL.PRG` 和 `GARMIN/APPS/BCPREVW.PRG`。安装前校验两个程序，逐个备份可见旧文件并回读校验；若只成功安装一个，会明确报告部分安装。固件隐藏的旧程序不能通过 USB 备份。本工具不写入活动记录、音乐或其他应用。

## 提前在手表上浏览外地赛道

安装会同时准备两个入口：**赛道预览**用于出发前查看，**Breadcrumb Trail** 用于徒步、越野跑中的地图数据页。

1. 拔掉 USB，返回手表表盘，按右上 **START** 打开运动／应用列表。
2. 打开 **赛道预览**（英文 **Race Preview**）。首次若没有出现在常用列表，可在列表底部“添加”中查找。
3. 启动时显示地图署名 5 秒，按 START 可提前进入地图。第一次打开自动显示全程，之后记住上次浏览位置。无需 GPS、手机或开始运动计时。
4. 浏览结束按 **BACK** 退出，再按平常方式打开徒步或越野跑。

| 赛道预览内按键 | 作用 |
| --- | --- |
| 缩放模式下 UP / DOWN | 放大 / 缩小；首次进入时默认使用缩放模式 |
| 短按右上 START | 依次切换“缩放 → 南北移动 → 东西移动” |
| 移动模式下 UP / DOWN | 向北 / 向南，或向西 / 向东 |
| 长按 UP | 菜单：缩放地图、南北移动、东西移动、查看全程、回到起点、地图来源 |
| 右下 BACK | 返回上一级；在地图页按 BACK 退出应用 |

赛道预览是独立应用，不启动定位、不记录活动，也不会更改运动数据页的跟随状态。
预览位置与缩放会保留；换赛事或改变地图细节、覆盖范围时重置。
它用于赛前查看，不保证能与原生运动记录同时运行。正式徒步或越野跑请使用原有的
Breadcrumb Trail 地图页；普通运动页的 UP/DOWN 仍切换心率、距离、时间等页面。

地图页不显示标题、按键说明或普通状态条。忘记当前操作模式时，长按 UP 可直接选择
“缩放地图”“南北移动”或“东西移动”；完整按键说明也保存在[项目 README](../readme.md#mac-离线版赛前浏览与按键)。
“地图来源”随时可查看图源署名和许可。记录运动时的越界警告仍会显示。

“查看全程”按圆形屏幕适配，给整条路线留出边距。缩放从全程概览到此次选择的最详细级别，
每一级都有提前下载的完整真实底图。移动接近覆盖边界时会停止，让整个视口留在已下载范围内；
这不代表手表会联网下载新的区域。正式记录运动时仍显示真实 GPS 位置，不把位置限制在地图内。
放大不会产生原图没有的细节，需要更细地图可在 Mac 选“详细”重新生成。
如果此前使用“标准”14 级，“详细”15 级可再放大一档；达到该级别后不继续进行数字放大。
旧比赛升级时，在 Mac 打开保存的比赛，点击“生成手表地图”，随后安装。
已有缓存会复用，缺少的缩放级别和覆盖范围会联网补充下载。
两个应用各自包含本次地图，因此所占存储约为此前单程序的两倍。

原数据字段的交互设置代码仍保留，供手表系统显示此入口时使用，但不再把它作为赛前预览入口。
实机此前已显示“赛道预览”和完整地图，却没有出现 Connect IQ Fields 菜单。
Garmin 官方论坛也记录过入口随运动状态和设备而变化的情况；这不足以确诊这台 255 的原因。
独立应用通过普通应用入口直接接收按键，避免依赖该菜单。

## 一次性准备

- macOS、Apple 命令行开发工具、Python 3.9+（推荐 Homebrew Python 3.13）。
- 从 [Garmin 官网](https://developer.garmin.com/connect-iq/sdk/)安装 SDK Manager，
  自行接受协议并登录；只需要 **一个当前 SDK** 和实际手表的设备文件。
  此版本在 SDK 9.3.0、`fr255` 上编译通过。
- SDK Manager → Preferences：SDK Updates / Device Updates 选 **Notify Me**，
  避免自动下载全部历史版本或其他机型。
- 在项目目录的终端运行 `zsh mac/Setup.command`：安装 Pillow、Java 和 libmtp，并构建本机应用。
  应用创建在 `build/` 中。首次需要联网；所需各级地图均已缓存时，可离线重新生成。
- 如果移动项目文件夹，重新运行初始化以更新应用的项目位置。

本机应用壳已签署本地临时签名；这不是已经公证、可独立分发的通用安装包。
官方 Garmin SDK 和本地签名密钥不随项目分发。

## 地图与容量

图源为 [OpenTopoMap](https://opentopomap.org/about)，使用 OpenStreetMap 和 SRTM，
包含山路、等高线和地形阴影。地图署名在独立预览启动时显示，并可从长按 UP 菜单的
“地图来源”重新查看；保留完整图源署名与 [CC BY-SA 3.0 地图许可](https://creativecommons.org/licenses/by-sa/3.0/)。
使用 WGS84 / Web Mercator，不混用国内互联网地图偏移坐标。

“路线周边”指定 GPX 外额外保留的范围。每个缩放级别都会准备包含整条 GPX 的完整矩形底图，
并自动补足至少半个最大支持屏幕的余量，确保浏览时满屏有图。因此实际覆盖范围会比狭窄的路线走廊更大，
不是仅沿路线两侧铺设一条地图。全程视图也使用相应级别的真实底图。

公共图源每次最多准备 256 张切片，**合计所有缩放级别**；单线程至多每秒一次请求，下载失败保留进度，
遇到限流停止；已下载内容直接复用。不使用 OSM 官网标准切片做离线预取。
此版本用于比赛路线附近，**不提供整省、整市批量下载**。地图数据是否包含当地山路，
取决于 OSM 与图源覆盖情况，预览可以提前检查。

“详细”使用 15 级，“标准”使用 14 级。赛道直接绘入切片，不截断 GPX 点、不连接
原始轨迹段之间的缺口。手表按需加载屏幕附近的原生位图，避免把整条路线的点数组
和全部地图同时放进运行内存。支持腕上预览缩放与平移；此版本不提供自动转弯提示或偏航距离计算。
原有 Garmin 原生 GPX 导航可以继续使用。

255 的数据字段运行内存是 256 KiB，不等于手表总存储。
256 张是产品下载上限，不是已经验证的最大可用地图容量。
完整矩形与多个缩放级别会增加下载量；超出上限时，可改选“标准”、缩小额外周边范围，或将长赛道分段准备。
大范围、长距离和高密度地图仍需实机确认；复制校验成功不代表运行与续航已验证。

## 验证和开发

```sh
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python mac/build_app.py
.venv/bin/python mac/server.py
# 启动官方模拟器后，将下方目录替换为实际生成地图的目录：
.venv/bin/python tools/test_watch_preview.py build/desktop-data/projects/比赛目录/watch
.venv/bin/python tools/test_watch_preview.py build/desktop-data/projects/比赛目录/watch --viewer
```

本地服务仅监听 `127.0.0.1`，每次启动生成访问令牌，并校验请求来源。
GPX、缓存、密钥、日志和备份都在被 Git 忽略的 `build/` 下，不上传至云端。
地图请求会把所需片区的切片坐标发送给图源。

独立预览在模拟器中验证了按键切换、地图平移、菜单回全程、放大及 BACK 退出。
两份程序已写入实际 255 并回读校验，用户已确认实机能进入“赛道预览”、缩放和移动。
v5 的 65 项 Python 测试通过，两个程序各通过 12 项官方模拟器逻辑测试，
包括 218/260 像素屏幕、各级缩放和四角极限移动的逐行地图覆盖检查。
已在模拟器目视确认满屏全程预览、详细地图与移动到边缘时无空白、无常驻文字。
公开测试路线使用 22 张真实切片，两个程序合计约 574 KiB，已写入实际 255 并回读校验。
用户已在真实 255 上确认 v5 缩到最小、移动到边缘均铺满屏幕，且没有常驻提示文字。
这项确认覆盖当前测试地图的显示与交互，不等于长距离运行或续航验证。
此前数据字段版本的上游公开示例 GPX 已在真实 255 上显示等高线、蓝色路线和全程预览；
数据字段设置入口未在这台手表的徒步菜单中出现。程序大小随所选路线、范围和细节变化。
室外定位跟随、长距离运行和续航仍待实机验证。

当前 USB 组件支持正常挂载的 Garmin 卷和 MTP。MTP 被占用时关闭 Garmin Express、
OpenMTP 等程序后重试。安装中保持连接；若发生中断，旧程序备份保留在 Mac 的
`build/desktop-data/backups/`。不要删除恢复所需的备份。
