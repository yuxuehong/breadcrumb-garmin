在手表上完成最后一步

拔掉 USB → 打开徒步或越野跑 → 长按左侧中键 UP → 徒步设置（或越野跑设置）→ 数据页面。先把地图页面的“布局”设为 1 个字段（全屏），再把唯一的数据字段设为 Connect IQ → Breadcrumb Trail。保留其他运动数据页面即可。徒步、越野跑的数据页面分别设置，各添加一次地图；无需重复安装。

看到“Use 1-field page”表示页面仍是多格布局，请改为全屏，无需重新安装。地图朝北，蓝线是路线，红点是当前位置；运动前没有 GPS 或人在外地时，自动显示赛道预览。请在出发前确认地图显示和覆盖范围。

提前浏览外地赛道：未开始运动且人在外地时，地图自动显示赛道全程。交互预览参考入口：长按 UP → Connect IQ Fields → Breadcrumb Trail，与“徒步设置 / 越野跑设置”同级。当前 255 的实机入口仍在核实；如果没有这一项，请保留现有地图页，无需反复安装。短按 UP / DOWN 缩放，START 切换为南北或东西移动；长按 UP 可查看全程、回起点或恢复定位跟随，BACK 退出预览，再返回运动数据页。预览位置不会被 GPS 拉回；正式开始运动会恢复跟随。
